# ldp-c2

Para iniciar este certamen usted debe ejecutar el siguiente comando:

´pip install -r librerias.txt´

Luego debe ejecutar:

´python manage.py runserver 0.0.0.0:8000´

Si usted ve un cohete celeste, felicidades, puede comenzar el certamen.

Recuerde que para poder hacer las migraciones usted debe ejecutar en el siguiente orden:

´python manage.py makemigrations´

´python manage.py migrate´
